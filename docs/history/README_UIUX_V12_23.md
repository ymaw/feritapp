# FeritApp UI/UX V12.23

Cambios:
- Header: foto de perfil alineada verticalmente con logo y nombre de FeritApp.
- Botón Atrás: ubicado a la izquierda, con espacio reservado para no superponerse con la marca.
- Subheaders: estilo unificado tomando como referencia la tarjeta de Ranking y preservando textos de cada vista.
- Ventas: tarjetas de clientes reorganizadas según la referencia adjunta, con estados Pendiente/Pago y Por entregar/Entregado.
- El estado de pago del cliente se cambia desde la tarjeta contraída; el cambio actualiza las ventas asociadas.
- En la tarjeta expandida, los artículos y total quedan a la izquierda; Messenger, Comprobante, Historial y Editar Venta a la derecha.
- No se modificó el repositorio original ni la base de datos remota.

Validación:
- Revisar el flujo visual en navegador con distintos tamaños de pantalla y probar cambios de estado con datos de prueba antes de desplegar.
